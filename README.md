# LawGlance

LawGlance is a lightweight static frontend for an AI-powered legal research assistant. It presents legal research, case-law browsing, agreement intelligence, and lawyer registration workflows in a responsive single-page interface.

## Files

- `index.html` - Page structure and content
- `styles.css` - Visual design and responsive layout
- `script.js` - Frontend interactions and action handlers

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static web server.
